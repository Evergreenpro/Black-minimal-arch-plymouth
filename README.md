# Black minimal arch

Based on: [HasanAgitUnal/ArchSliderGlowPlymouth](https://github.com/HasanAgitUnal/ArchSliderGlowPlymouth)

# Installation

Install with these commands:
```bash
git clone https://github.com/Evergreenpro/Black-minimal-arch-plymouth.git
cd Black-minimal-arch-plymouth
sudo ./install.sh install
```

You can remove theme if you didnt deleted cloned repo folder.
Go to the repo directory and run:
```bash
sudo ./install remove
```
